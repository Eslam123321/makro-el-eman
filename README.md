# 🌾 مصنع الإيمان للمكرونة - ERP Enterprise Management System

نظام إدارة موارد المؤسسات (ERP) المتكامل والمتطور لمصنع وتجارة المكرونة بالشكارة.

---

## ✨ المميزات الرئيسية للنظام:
- 📊 **لوحة تحكم تنفيذية ذكية (Executive Dashboard):** رسوم بيانية تفاعلية لمراقبة المبيعات، المصروفات، الأرباح الصافية، والسيولة اللحظية.
- 🧾 **إدارة المبيعات وفواتير الشكاير (POS & Invoicing):** إصدار فواتير بيع الشكاير، نظام المرتجعات الجزئية والكلية، وطباعة الفواتير مع الختم المائي والعلامة الرسمية.
- 📦 **المخازن وإدارة الأصناف (Inventory):** متابعة أرصدة الشكاير، التكلفة، وتنبيهات النواقص التلقائية.
- 👥 **حسابات العملاء والمديونيات (CRM):** متابعة حسابات العملاء، سداد الديون، وتواريخ الاستحقاق.
- 🚚 **الموردين والمطاحن (Suppliers):** تسجيل توريدات الدقيق، كشوف الحساب، وسداد المستحقات.
- 💼 **المصروفات والخزينة (Treasury & Expenses):** تسجيل المصروفات التشغيلية ومتابعة حركة النقدية.
- 👨‍💼 **الموارد البشرية والرواتب (HR):** إدارة الموظفين، الحضور والانصراف، وحساب الرواتب والخصومات.
- 📈 **الجرد والتقارير المالية (Reports & Audits):** تقارير مالية وجرد دوري شامل وتصدير Excel/PDF.
- 🔐 **الأمان والصلاحيات السحابية (Firebase Cloud Sync):** مزامنة حية وفورية لكافة البيانات عبر سحابة Google Firebase Firestore.

---

## 🛠️ التقنيات المستخدمة:
- **Frontend:** Vanilla JavaScript (ES6+), HTML5, Modern Responsive CSS3 (Glassmorphism & Clean Luxury UI).
- **Backend & Cloud:** Google Firebase Firestore Realtime Cloud Sync.
- **Libraries:** Chart.js, HTML2Canvas, HTML2PDF, FontAwesome Pro.
